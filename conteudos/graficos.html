Gráficos — Tipos, Criação e Edição

Os gráficos permitem representar visualmente os dados, facilitando a interpretação e a comunicação de informação. Aprenda a escolher o tipo certo, criar, editar e formatar gráficos no Excel.

📊

1. Tipos de Gráficos

A escolha do tipo de gráfico depende do tipo de dados e da mensagem que se pretende transmitir.

TipoQuando usarExemplo de uso
ColunasComparar valores entre categoriasVendas por mês, resultados por produto
BarrasComparar categorias (especialmente com nomes longos)Ranking de produtos, comparação de países
LinhasMostrar tendências ao longo do tempoEvolução de preços, temperatura ao longo do ano
Circular (Pizza)Mostrar proporções de um todo (percentagens)Quota de mercado, distribuição de despesas
ÁreaMostrar volumes acumulados ao longo do tempoVendas acumuladas, crescimento de utilizadores
Dispersão (XY)Analisar a relação entre duas variáveis numéricasCorrelação entre preço e procura
HistogramaMostrar a distribuição de frequênciasDistribuição de idades, notas de alunos
CombinadoCombinar dois tipos de gráfico (ex.: colunas + linha)Vendas (colunas) + margem (linha)
💡
Regra de ouro na escolha do gráfico:

Colunas/Barras → comparar categorias | Linhas → tendências no tempo | Circular → proporções (máx. 5-6 fatias) | Dispersão → correlação entre variáveis numéricas

➕

2. Criar um Gráfico

Passo a Passo

  1. Selecione os dados que pretende representar, incluindo os cabeçalhos (títulos das colunas e linhas).
  2. No separador Inserir, escolha o tipo de gráfico pretendido no grupo Gráficos.
  3. O gráfico é inserido automaticamente na folha de cálculo.
  4. Mova e redimensione o gráfico conforme necessário.
⚠️

Selecione sempre os dados com os cabeçalhos. Uma seleção incorreta produz gráficos com dados errados ou sem legendas. Verifique sempre a pré-visualização antes de confirmar.

Gráfico Recomendado

Se não tiver a certeza do tipo de gráfico mais adequado, use Inserir > Gráficos Recomendados. O Excel analisa os dados e sugere os tipos mais adequados.

Mover o Gráfico para uma Folha Separada

  1. Clique com o botão direito no gráfico.
  2. Escolha Mover Gráfico.
  3. Selecione Nova Folha e dê um nome à folha.
  4. Clique em OK.
✏️

3. Editar e Formatar Gráficos

Ao clicar num gráfico, aparecem dois separadores contextuais no friso: Estrutura do Gráfico e Formatar.

Separador Estrutura do Gráfico

OpçãoO que permite fazer
Adicionar Elemento de GráficoAdicionar/remover título, legenda, rótulos de dados, linhas de grelha, eixos
Esquema RápidoAplicar um esquema predefinido de elementos
Estilos de GráficoAlterar o estilo visual (cores, efeitos)
Alternar Linha/ColunaTrocar os dados das linhas pelas colunas e vice-versa
Selecionar DadosAlterar o intervalo de dados do gráfico
Alterar Tipo de GráficoMudar para outro tipo de gráfico
Mover GráficoMover para outra folha ou para uma folha de gráfico

Alterar os Dados de Origem

  1. Clique no gráfico.
  2. No separador Estrutura do Gráfico, clique em Selecionar Dados.
  3. Altere o intervalo de dados ou adicione/remova séries.
  4. Clique em OK.
💡

Quando os dados da folha são alterados, o gráfico atualiza-se automaticamente. Não é necessário recriar o gráfico.

🏷️

4. Elementos do Gráfico

ElementoDescriçãoComo adicionar/editar
Título do gráficoTexto descritivo no topo do gráficoClicar no título e escrever; ou Estrutura > Adicionar Elemento > Título do Gráfico
Títulos dos eixosEtiquetas dos eixos X e YEstrutura > Adicionar Elemento > Títulos dos Eixos
LegendaIdentifica as séries de dados por corEstrutura > Adicionar Elemento > Legenda (posição: direita, esquerda, topo, baixo)
Rótulos de dadosMostra os valores em cada ponto/barra do gráficoEstrutura > Adicionar Elemento > Rótulos de Dados
Linhas de grelhaLinhas horizontais/verticais de referênciaEstrutura > Adicionar Elemento > Linhas de Grelha
Tabela de dadosMostra os dados numéricos abaixo do gráficoEstrutura > Adicionar Elemento > Tabela de Dados
Linha de tendênciaMostra a tendência geral dos dadosBotão direito na série > Adicionar Linha de Tendência

Formatar Elementos Individualmente

  • Duplo clique em qualquer elemento do gráfico abre o painel de formatação lateral.
  • Pode alterar cores, bordas, preenchimentos, tamanho de texto e muito mais.
  • Para formatar uma série específica: clique uma vez para selecionar todas as barras/pontos, depois clique novamente numa barra/ponto específico para selecionar apenas esse.
✅

5. Boas Práticas na Criação de Gráficos

✅
O que fazer
  • Escolher o tipo de gráfico adequado ao tipo de dados e à mensagem.
  • Incluir sempre um título descritivo e claro.
  • Adicionar rótulos de dados quando os valores exatos são importantes.
  • Usar cores com contraste suficiente para facilitar a leitura.
  • Manter o gráfico simples — menos é mais.
  • Verificar se os eixos têm escala adequada (não começar sempre em zero pode distorcer a perceção).
❌
O que evitar
  • Gráficos circulares com mais de 5-6 fatias (difíceis de ler).
  • Efeitos 3D que distorcem a perceção dos valores.
  • Demasiadas cores ou padrões que confundem o leitor.
  • Gráficos sem título ou sem identificação dos eixos.
  • Usar o tipo de gráfico errado (ex.: circular para mostrar tendências no tempo).
🎓

6. Aptidões e Atitudes a Desenvolver

✅ Aptidões
  • Selecionar o tipo de gráfico adequado aos dados
  • Criar gráficos a partir de dados selecionados
  • Adicionar e editar título, legenda e rótulos de dados
  • Alterar o tipo de gráfico e os dados de origem
  • Formatar elementos individuais do gráfico
  • Mover o gráfico para uma folha separada
🌟 Atitudes
  • Sentido crítico na escolha do tipo de gráfico
  • Clareza e objetividade na comunicação visual
  • Atenção à legibilidade e ao design
  • Rigor na representação fiel dos dados
