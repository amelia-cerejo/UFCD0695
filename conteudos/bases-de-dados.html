🗂️ O que é uma Base de Dados?

Definição

Uma base de dados é um conjunto organizado de informação armazenada de forma estruturada, que permite guardar, pesquisar, atualizar e gerir grandes volumes de dados de forma eficiente e fiável.

Pensa numa base de dados como um arquivo digital muito bem organizado — em vez de papéis espalhados numa gaveta, tens toda a informação catalogada, pesquisável e sempre disponível.

Para que serve uma Base de Dados?

NecessidadeSem Base de DadosCom Base de Dados
Guardar informaçãoPapéis, post-its, ficheiros soltosTudo num só local, organizado e seguro

Boas Práticas de Introdução de Dados

  • Usa sempre a primeira linha para os cabeçalhos das colunas
  • Não deixes linhas ou colunas em branco no meio dos dados
  • Mantém um tipo de dado consistente em cada coluna
  • Evita espaços extra antes ou depois do texto nas células
  • Usa a validação de dados (Dados › Validação) para restringir entradas incorretas
  • Converte os dados numa Tabela do Excel (Ctrl+T) para maior eficiência

5 Passos para Planificar uma Base de Dados

  • Definir o Objetivo — O que preciso de saber? Que informação vou gerir?
  • Identificar as Entidades (Tabelas) — Que "coisas" distintas preciso de registar? (ex: Clientes, Produtos, Encomendas)
  • Definir os Campos de cada Tabela — Que atributos tem cada entidade? Qual é a chave primária?
  • Definir as Relações — Como se ligam as tabelas? Qual o tipo de relação (1:N, N:M)?
  • Verificar a Planificação — Cada tabela tem PK? Há informação repetida? Todos os dados necessários estão contemplados?
📌 Regra de ouro: Só avança para o Access depois de validar a planificação no papel. Uma BD mal planificada é muito difícil de corrigir depois de criada.

Excel vs Access — Quando usar cada um?

📊 Excel
  • Cálculos e análise numérica
  • Gráficos e visualizações
  • Dados simples numa só tabela
  • Relatórios financeiros
  • Até ~10.000 registos
  • Uso individual ou pequena equipa
  • Tabelas dinâmicas e dashboards
🗄️ Access
  • Dados com relações entre tabelas
  • Grandes volumes de registos
  • Formulários de introdução de dados
  • Consultas complexas (SQL)
  • Múltiplos utilizadores simultâneos
  • Relatórios estruturados para impressão
  • Integridade referencial garantida
💡 Regra prática: Se precisas de calcular, usa o Excel. Se precisas de gerir e relacionar informação, usa o Access.
