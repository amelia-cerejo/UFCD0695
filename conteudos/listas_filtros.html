Listas, Ordenação e Filtros de Dados

Estruturar dados como tabela formatada, garantir a qualidade dos dados e utilizar ordenação e filtros para responder a questões concretas sobre a informação.

📋

1. Estrutura de uma Lista de Dados

Uma lista de dados (ou base de dados) é um conjunto de informação organizado em linhas e colunas, onde cada linha representa um registo e cada coluna representa um campo.

Regras para uma Lista Bem Estruturada

✅
  • Um único cabeçalho por coluna — cada coluna tem um nome único e descritivo na primeira linha.
  • Sem linhas ou colunas vazias no interior dos dados.
  • Cada coluna contém sempre o mesmo tipo de informação (ex.: a coluna "Data" só tem datas).
  • Sem células unidas dentro da área de dados.
  • Dados consistentes — mesma ortografia, mesmo formato de data, mesmas categorias.

Erros Comuns a Corrigir

ProblemaExemploSolução
Inconsistência de texto"Lisboa", "lisboa", "LISBOA"Uniformizar com maiúsculas/minúsculas
Espaços extra" Lisboa" (com espaço antes)Usar a função =COMPACTAR() para remover espaços
Datas em formato texto"01-01-2026" como textoConverter para formato de data reconhecido pelo Excel
Números como texto"100" (alinhado à esquerda)Converter para número (Dados > Texto para Colunas)
Categorias inconsistentes"Norte", "norte", "Região Norte"Definir uma lista de valores válidos e uniformizar
📊

2. Tabela Formatada

Uma tabela formatada é um intervalo de dados que o Excel reconhece como uma unidade estruturada. Oferece funcionalidades automáticas de filtragem, ordenação, formatação e cálculo.

Converter um Intervalo em Tabela

  1. Clique em qualquer célula dentro do intervalo de dados.
  2. No separador Inserir, clique em Tabela (ou Ctrl + T).
  3. Confirme o intervalo e verifique se a opção "A minha tabela tem cabeçalhos" está ativa.
  4. Clique em OK.

Nomear a Tabela

Após criar a tabela, atribua-lhe um nome descritivo:

  1. Clique dentro da tabela.
  2. No separador Estrutura da Tabela, escreva o nome na caixa Nome da Tabela.
  3. Use nomes sem espaços: VendasMensais, ListaProdutos, RegistoClientes.

Vantagens das Tabelas Formatadas

VantagemDescrição
Setas de filtro automáticasAparecem automaticamente nos cabeçalhos
Expansão automáticaAo adicionar dados abaixo ou à direita, a tabela expande-se automaticamente
Fórmulas automáticasAs fórmulas são aplicadas automaticamente às novas linhas
Referências estruturadasAs fórmulas usam nomes de colunas em vez de referências de células (ex.: =[@Preço]*[@Quantidade])
Linha de totaisPermite adicionar cálculos automáticos no final da tabela
Estilos visuaisFormatação alternada de linhas para melhor legibilidade
💡

As tabelas formatadas são o ponto de partida recomendado antes de criar tabelas dinâmicas. Ao acrescentar registos, basta atualizar a tabela dinâmica para os integrar na análise.

↕️

3. Ordenação de Dados

Ordenação Simples

  1. Clique em qualquer célula da coluna pela qual pretende ordenar.
  2. No separador Dados, clique em Ordenar de A a Z (crescente) ou Ordenar de Z a A (decrescente).

Ou use as setas de filtro nos cabeçalhos da tabela: clique na seta > escolha a ordenação pretendida.

Ordenação por Vários Níveis

  1. Clique em qualquer célula da tabela.
  2. No separador Dados, clique em Ordenar.
  3. Defina o primeiro nível de ordenação (coluna e direção).
  4. Clique em Adicionar Nível para adicionar mais critérios.
  5. Confirme com OK.
💡

Exemplo: ordenar primeiro por Categoria (A-Z) e depois por Preço (decrescente). Dentro de cada categoria, os produtos ficam ordenados do mais caro para o mais barato.

Tipos de Ordenação

Tipo de dadosCrescenteDecrescente
TextoA → ZZ → A
NúmerosMenor → MaiorMaior → Menor
DatasMais antiga → Mais recenteMais recente → Mais antiga
Cor de célulaCor selecionada no topoCor selecionada no fundo

4. Filtros de Dados

Os filtros ocultam temporariamente as linhas que não cumprem os critérios definidos. Os dados não são eliminados — ficam apenas invisíveis até o filtro ser removido.

Aplicar um Filtro

  1. Clique na seta de filtro do cabeçalho da coluna pretendida.
  2. Escolha os critérios de filtragem na lista ou use as opções avançadas.
  3. Clique em OK para aplicar.

As linhas filtradas ficam ocultas e os números das linhas visíveis aparecem a azul. A seta do cabeçalho filtrado muda para um ícone de funil.

Tipos de Filtros

TipoOpções disponíveisExemplo
Filtros de TextoIgual a, Não igual a, Começa por, Termina em, Contém, Não contémMostrar apenas registos onde Cidade = "Lisboa"
Filtros de NúmeroIgual a, Maior que, Menor que, Entre, Acima da média, Abaixo da médiaMostrar produtos com preço > 50 €
Filtros de DataHoje, Esta semana, Este mês, Este ano, Antes de, Depois de, EntreMostrar vendas do mês atual
Filtro por corFiltrar por cor de célula ou cor de textoMostrar apenas células marcadas a vermelho
Seleção manualMarcar/desmarcar valores específicos da listaMostrar apenas "Norte" e "Sul"

Filtros Combinados

É possível aplicar filtros em várias colunas simultaneamente. Os critérios são combinados com E (AND) — só aparecem os registos que cumprem todos os critérios ativos.

// Exemplo: filtrar por Cidade E por Preço
Coluna Cidade: filtrar "Lisboa"
Coluna Preço: filtrar "> 100"
→ Mostra apenas registos de Lisboa com preço > 100 €

Limpar Filtros

  • Limpar filtro de uma coluna: clique na seta de filtro > Limpar Filtro de "[nome da coluna]".
  • Limpar todos os filtros: separador Dados > Limpar.
  • Desativar filtros: separador Dados > Filtrar (remove as setas de filtro).
⚠️

Os filtros ocultam linhas mas não eliminam dados. Para repor todos os registos, limpe os filtros ativos. Verifique sempre se existem filtros ativos antes de fazer cálculos ou análises.

➕

5. Linha de Totais

A linha de totais é uma funcionalidade exclusiva das tabelas formatadas que adiciona automaticamente cálculos no final da tabela.

Ativar a Linha de Totais

  1. Clique dentro da tabela formatada.
  2. No separador Estrutura da Tabela, ative a opção Linha de Totais.
  3. Uma nova linha aparece no final da tabela.
  4. Clique numa célula da linha de totais e escolha o tipo de cálculo na lista pendente.

Cálculos Disponíveis na Linha de Totais

CálculoFunção utilizadaQuando usar
Soma=SUBTOTAL(109;...)Somar valores numéricos (ignora linhas ocultas por filtro)
Média=SUBTOTAL(101;...)Calcular a média dos valores visíveis
Contagem=SUBTOTAL(102;...)Contar células com números
Contagem de números=SUBTOTAL(103;...)Contar células não vazias
Máximo=SUBTOTAL(104;...)Valor mais alto
Mínimo=SUBTOTAL(105;...)Valor mais baixo
ℹ️

A linha de totais usa a função SUBTOTAL que ignora as linhas ocultas por filtro. Assim, quando aplica um filtro, os totais atualizam-se automaticamente para refletir apenas os dados visíveis.

🎓

6. Aptidões e Atitudes a Desenvolver

✅ Aptidões
  • Estruturar dados com cabeçalhos únicos e sem linhas vazias
  • Converter um intervalo em tabela formatada
  • Nomear a tabela com um nome descritivo
  • Ordenar dados por um ou vários critérios
  • Aplicar filtros de texto, número e data
  • Combinar filtros em várias colunas
  • Limpar filtros e repor todos os registos
  • Ativar e configurar a linha de totais
🌟 Atitudes
  • Método e rigor na organização dos dados
  • Pensamento crítico na análise dos resultados
  • Atenção à consistência e qualidade dos dados
  • Cuidado para não eliminar dados ao filtrar
