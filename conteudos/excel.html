📋 Tabelas do Excel

Como criar uma Tabela

  • Clica numa célula dentro dos dados
  • Vai a Inserir › Tabela ou usa o atalho Ctrl+T
  • Confirma o intervalo e se a tabela tem cabeçalhos
  • Escolhe um estilo de tabela no separador Estrutura da Tabela
  • Dá um nome descritivo à tabela (ex: tblVendas)

Ordenar e Filtrar

Ordenar:

  • Seleciona uma célula na coluna a ordenar
  • Vai a Dados › Ordenar
  • Escolhe coluna, critério e ordem (A→Z ou Z→A)
  • Adiciona níveis para ordenação múltipla

Filtrar:

  • Clica numa célula dentro dos dados
  • Usa Ctrl+Shift+L para ativar filtros
  • Clica na seta do cabeçalho para filtrar
  • Usa "Filtro de Texto/Número" para critérios avançados

Destaca automaticamente células com base no seu valor. Acede em Base › Formatação Condicional.

Exemplo Prático — Destacar despesas não pagas

  • Seleciona o intervalo de dados (ex: A2:E20)
  • Vai a Base › Formatação Condicional › Nova Regra
  • Escolhe "Utilizar uma fórmula para determinar as células a formatar"
  • Escreve a fórmula: =$E2="Não" (coluna E = coluna "Pago")
  • Clica em Formatar e escolhe fundo vermelho claro
  • Confirma com OK
💡 Atenção ao $ na fórmula: Usa =$E2 (coluna fixa, linha variável) para que a regra se aplique a toda a linha com base no valor da coluna E.

Funções com Critérios

FunçãoSintaxeDescrição
SOMASE=SOMASE(intervalo;critério;soma)Soma células que cumprem uma condição
SOMASES=SOMASES(soma;int1;crit1;int2;crit2)Soma com múltiplos critérios
CONT.SE=CONT.SE(intervalo;"Lisboa")Conta células que cumprem uma condição
CONT.SES=CONT.SES(int1;crit1;int2;crit2)Conta com múltiplos critérios
MÉDIASE=MÉDIASE(intervalo;critério;média)Média com critério

Funções de Pesquisa

FunçãoSintaxeDescrição
PROCV=PROCV(valor;tabela;col;0)Procura vertical (coluna mais à esquerda). Clássico.
PROCH=PROCH(valor;tabela;linha;0)Procura horizontal (linha de cima)
PROCX=PROCX(valor;pesquisa;retorno)Versão moderna do PROCV — mais flexível ✨
ÍNDICE=ÍNDICE(intervalo;linha;col)Devolve o valor numa posição específica
CORRESP=CORRESP(valor;intervalo;0)Devolve a posição de um valor num intervalo
ℹ️ PROCX vs PROCV: O PROCX é mais poderoso — procura em qualquer direção, não precisa que a coluna de pesquisa seja a primeira, e tem melhor tratamento de erros. Disponível no Excel 2021 e Microsoft 365.

Função SE — Simples e Aninhada

TipoExemploResultado

SE com E=SE(E(A1>=10;B1="Sim");"OK";"Não OK")Ambas as condições têm de ser verdadeiras
SE com OU=SE(OU(A1="Lisboa";A1="Porto");"Norte/Sul";"Outro")Basta uma condição ser verdadeira
SEERRO=SEERRO(PROCV(...);"Não encontrado")Substitui erros por texto amigável

Como criar um Gráfico

  • Seleciona os dados a representar (incluindo cabeçalhos)
  • Vai a Inserir › Gráficos e escolhe o tipo
  • O gráfico é inserido na folha — arrasta para a posição desejada
  • Usa as Ferramentas de Gráfico (separadores Design e Formato) para personalizar
  • Adiciona título, etiquetas de dados e legenda conforme necessário
💡 Atalho rápido: Seleciona os dados e prime Alt+F1 para inserir um gráfico de colunas instantaneamente na folha atual, ou F11 para criar numa folha separada.

Criar uma Tabela Dinâmica

  • Clica numa célula dentro dos dados (idealmente numa Tabela do Excel)
  • Vai a Inserir › Tabela Dinâmica
  • Escolhe se a TD fica numa nova folha ou na folha atual
  • No painel direito, arrasta os campos para as áreas: Filtros, Colunas, Linhas e Valores
  • Clica com o botão direito nos valores para alterar o tipo de cálculo (Soma, Média, Contagem…)
  • Para atualizar após alterar os dados originais: clica com o botão direito › Atualizar

✅ Validação de Dados

A validação de dados restringe o tipo ou intervalo de valores que podem ser introduzidos numa célula, reduzindo erros de introdução.

Como configurar a Validação de Dados

  • Seleciona as células onde queres aplicar a validação
  • Vai a Dados › Validação de Dados
  • Em "Permitir", escolhe o tipo de validação
  • Define os critérios (mínimo, máximo, lista, etc.)
  • No separador "Mensagem de Entrada", adiciona uma dica para o utilizador
  • No separador "Alerta de Erro", define a mensagem de erro
Tipo de ValidaçãoDescriçãoExemplo
Número InteiroAceita apenas números inteiros num intervaloEntre 1 e 100
DecimalAceita números com casas decimaisEntre 0,00 e 9999,99
ListaCria uma lista suspensa (dropdown)Sim;Não;Pendente
DataAceita apenas datas num intervaloEntre 01/01/2024 e 31/12/2026
Comprimento do TextoLimita o número de caracteresMáximo 9 caracteres (NIF)
PersonalizadoUsa uma fórmula como critério=NÚM.CARACT(A1)=9
💡 Lista suspensa a partir de um intervalo: Em vez de escrever os valores separados por ponto e vírgula, podes apontar para um intervalo de células (ex: =$G$1:$G$5) — assim a lista atualiza automaticamente quando alteras os valores.

🚨 Erros Comuns e Como Corrigir

ErroCausaSolução
#DIV/0! Divisão por zero ou por célula vazia Usa =SEERRO(A1/B1;0) para substituir por 0
#VALOR! Tipo de dado errado (ex: texto numa fórmula numérica) Verifica se as células têm o tipo de dado correto
#REF! Referência inválida (célula eliminada ou movida) Corrige a fórmula para apontar para o intervalo correto
#NOME? Nome de função mal escrito ou não reconhecido Verifica a ortografia da função (ex: SOMA e não SOMA())
#N/D Valor não encontrado (comum no PROCV/PROCX) Usa =SEERRO(PROCV(...);"Não encontrado")
#NÚM! Valor numérico inválido (ex: raiz de número negativo) Verifica os valores de entrada da fórmula
###### Coluna demasiado estreita para mostrar o valor Alarga a coluna — duplo clique na borda do cabeçalho
#NULO! Interseção de dois intervalos que não se cruzam Verifica os operadores de intervalo na fórmula
💡 Ferramenta de diagnóstico: Usa Fórmulas › Verificar Erros para o Excel identificar e explicar os erros na folha automaticamente.

📝 Exercícios Práticos

📋 Exercício 1 — Lista de Contactos Básico
  1. Cria um novo livro Excel e guarda-o como Contactos_Empresa.xlsx
  2. Na Folha1, cria uma tabela com as colunas: Nome, Apelido, Departamento, Telefone, E-mail, Data de Entrada
  3. Introduz 10 registos fictícios com dados coerentes
  4. Formata a coluna "Data de Entrada" como data (DD/MM/AAAA)
  5. Converte o intervalo numa Tabela do Excel e aplica um estilo
  6. Ordena por Departamento (A→Z) e depois por Apelido (A→Z)
  7. Filtra para mostrar apenas os colaboradores do departamento "Recursos Humanos"
💰 Exercício 2 — Controlo de Despesas Intermédio
  1. Cria uma nova folha chamada Despesas_Mensais
  2. Cria colunas: Data, Categoria, Descrição, Valor (€), Pago (Sim/Não)
  3. Adiciona validação de dados na coluna "Pago" com lista: Sim;Não
  4. Introduz 15 registos de despesas variadas
  5. Usa =SOMA() para calcular o total de despesas
  6. Usa =SOMASE() para somar apenas as despesas pagas
  7. Aplica formatação condicional para destacar a vermelho as despesas não pagas
📊 Exercício 3 — Análise de Vendas com Tabela Dinâmica Avançado
  1. Cria uma folha com dados de vendas: Data, Vendedor, Produto, Região, Quantidade, Preço Unitário
  2. Adiciona uma coluna Total com a fórmula =Quantidade*Preço Unitário
  3. Converte os dados numa Tabela do Excel
  4. Cria uma Tabela Dinâmica que mostre o total de vendas por Vendedor e por Região
  5. Adiciona um Gráfico de Colunas baseado na Tabela Dinâmica
  6. Usa PROCV ou PROCX para pesquisar o total de vendas de um vendedor específico
  7. Aplica formatação condicional com escala de cor nos totais
