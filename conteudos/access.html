📖 Conceitos Fundamentais

🗄️

Base de Dados

Conjunto organizado de dados relacionados, geridos por um SGBD

📋

Tabela

Estrutura com linhas (registos) e colunas (campos) que armazena dados

➡️

Registo

Uma linha da tabela — representa uma entidade (ex: um cliente)

⬇️

Campo

Uma coluna da tabela — representa um atributo (ex: Nome, Data)

🔑

Chave Primária (PK)

Campo único que identifica inequivocamente cada registo

🔗

Chave Estrangeira (FK)

Campo que referencia a PK de outra tabela, criando uma relação

↔️

Relação

Ligação entre tabelas através de campos comuns (1:1, 1:N, N:M)

🔍

Consulta (Query)

Instrução para extrair, filtrar e combinar dados de tabelas

📐 Planificação de uma Base de Dados

⚠️ Regra de ouro: Nunca cries tabelas no Access sem antes planificar no papel. Uma base de dados mal planificada é muito difícil de corrigir depois de ter dados introduzidos.

5 Passos de Planificação

  • Definir o Objetivo
    O que preciso de saber? Que informação vou gerir? Quem vai usar a BD?
  • Identificar as Entidades (Tabelas)
    Que "coisas" distintas preciso de registar? Cada entidade será uma tabela.
  • Definir os Campos de cada Tabela
    Que atributos tem cada entidade? Qual é a chave primária? Que tipo de dados?
  • Definir as Relações entre Tabelas
    Como se ligam as tabelas? Qual o tipo de relação (1:1, 1:N, N:M)?
  • Verificar a Planificação
    Cada tabela tem PK? Há informação repetida? Todos os dados necessários estão contemplados?

✅ Checklist de Verificação da Planificação

  • Cada tabela tem uma chave primária definida?
  • Não há informação repetida desnecessariamente entre tabelas?
  • As relações estão estabelecidas através de campos comuns?
  • Todos os dados necessários estão contemplados?
  • Os tipos de dados são adequados ao conteúdo de cada campo?
  • Os campos de texto têm tamanho adequado definido?
  • As chaves estrangeiras têm o mesmo tipo de dados que a PK referenciada?

Tipos de Relações

TipoDescriçãoExemplo
1 : 1 Um registo de A corresponde a exatamente um registo de B Pessoa ↔ Bilhete de Identidade
1 : N Um registo de A pode corresponder a vários registos de B (o mais comum) Cliente → Encomendas
N : M Vários registos de A correspondem a vários de B (requer tabela intermédia) Alunos ↔ Disciplinas

📋 Criar e Gerir Tabelas

Criar uma Tabela em Vista de Estrutura

  • Abre o Access e cria uma nova base de dados em branco
  • No separador Criar, clica em Estrutura da Tabela
  • Define os campos: escreve o Nome do Campo, escolhe o Tipo de Dados e define as propriedades em baixo
  • Define a Chave Primária: clica com o botão direito no campo e seleciona Chave Primária (ícone 🔑)
  • Guarda a tabela com Ctrl+S e dá-lhe um nome descritivo (ex: tblClientes)

💡 Numeração Automática como PK: Para a maioria das tabelas, usa um campo Numeração Automática como chave primária (ex: ID_Cliente). O Access gera o número automaticamente e garante que é único.

Criar Relações no Access

  • Vai a Ferramentas de Base de Dados › Relações
  • Clica em Mostrar Tabela e adiciona todas as tabelas necessárias
  • Arrasta o campo PK de uma tabela para o campo FK da outra
  • Na janela que aparece, ativa "Impor Integridade Referencial"
  • Ativa também "Atualização em Cascata" e "Eliminação em Cascata" se necessário
  • Clica em Criar — aparece uma linha a ligar as tabelas
ℹ️ Integridade Referencial: Ao ativar esta opção, o Access impede que sejas adicionado um registo na tabela "filho" (ex: Veículo) sem que exista o registo correspondente na tabela "pai" (ex: Condómino). Garante a consistência dos dados.

📝 Formulários

Os formulários facilitam a introdução e visualização de dados, apresentando os registos de forma mais amigável do que a vista de folha de dados.

Criar Formulário Automático

  • Seleciona a tabela ou consulta na barra de navegação
  • Vai a Criar › Formulário
  • O Access cria automaticamente um formulário básico
  • Guarda com Ctrl+S e dá um nome (ex: frmClientes)

Assistente de Formulários

  • Vai a Criar › Assistente de Formulários
  • Escolhe a tabela/consulta e os campos a incluir
  • Seleciona o esquema (Colunas, Tabular, Folha de Dados)
  • Escolhe o estilo e dá um nome ao formulário

Vistas do Formulário

VistaUtilização
Vista de FormulárioUtilização normal — introdução e visualização de dados
Vista de EstruturaPersonalização avançada — mover, redimensionar e formatar controlos
Vista de EsquemaPersonalização visual com pré-visualização dos dados reais
Vista de Folha de DadosApresenta os dados em formato de tabela (como a tabela original)
💡 Formulário com subformulário: Para relações 1:N (ex: Cliente e as suas Encomendas), usa o Assistente de Formulários e seleciona campos de ambas as tabelas — o Access cria automaticamente um formulário principal com subformulário.

📊 Relatórios

Os relatórios permitem apresentar os dados de forma formatada e pronta para impressão ou exportação.

Criar Relatório Automático

  • Seleciona a tabela ou consulta
  • Vai a Criar › Relatório
  • O Access gera um relatório automático
  • Guarda com nome descritivo (ex: rptVendasMensais)

Assistente de Relatórios

  • Vai a Criar › Assistente de Relatórios
  • Escolhe os campos a incluir
  • Define agrupamentos e ordenação
  • Escolhe o esquema e o estilo

Funcionalidades dos Relatórios

FuncionalidadeDescrição
AgrupamentoAgrupa registos por um campo (ex: por Departamento)
OrdenaçãoOrdena os registos dentro de cada grupo
Totais e SubtotaisSoma, média, contagem por grupo e total geral
Cabeçalho/RodapéInformação que aparece no início/fim de cada página ou grupo
Exportar para PDFDados Externos › PDF ou XPS — exporta o relatório para PDF
Exportar para ExcelDados Externos › Excel — exporta os dados para uma folha de cálculo

📝 Exercícios Práticos

🏢 Exercício 1 — Base de Dados de Fornecedores Básico
  1. Cria uma nova base de dados chamada Fornecedores.accdb
  2. Cria a tabela tblFornecedores com os campos: ID_Fornecedor (Numeração Auto., PK), Nome, NIF, Morada, Cidade, Telefone, E-mail, Ativo (Sim/Não)
  3. Cria a tabela tblProdutos com os campos: ID_Produto (Numeração Auto., PK), Designação, Preço_Unitário (Moeda), Stock (Número), ID_Fornecedor (Número, FK)
  4. Cria uma relação 1:N entre tblFornecedores e tblProdutos com integridade referencial
  5. Introduz 5 fornecedores e 10 produtos
  6. Cria uma consulta qryProdutosFornecedor que mostre: Nome do Fornecedor, Designação do Produto e Preço Unitário
  7. Cria um formulário frmFornecedores para introdução de novos fornecedores
  8. Cria um relatório rptProdutosPreco com a lista de produtos ordenada por preço (decrescente)
🏠 Exercício 2 — Garagem de Condomínio Intermédio
  1. Cria uma nova base de dados chamada GaragemCondominio.accdb
  2. Planifica e cria as tabelas: tblCondóminos, tblVeículos e tblMarcas com os campos e tipos de dados adequados
  3. Define as chaves primárias e estrangeiras em cada tabela
  4. Cria as relações entre as tabelas com integridade referencial
  5. Introduz pelo menos 5 condóminos, 4 marcas e 8 veículos
  6. Cria a consulta qryVeiculosAtivos que mostre apenas os veículos com autorização ativa, incluindo o nome do condómino e a marca
  7. Cria a consulta qryVeiculosPorMarca com critério para filtrar por marca (usando parâmetro: [Introduza a marca:])
  8. Cria um formulário frmCondóminos com subformulário dos veículos de cada condómino
  9. Cria um relatório rptListaVeiculos agrupado por condómino
🎓 Exercício 3 — Gestão de Formações Avançado
  1. Cria uma base de dados GestaoFormacoes.accdb para gerir formandos, formações e inscrições
  2. Identifica as entidades necessárias e planifica as tabelas no papel antes de criar no Access
  3. Cria todas as tabelas com os campos adequados, chaves primárias e relações
  4. Introduz dados de teste: pelo menos 10 formandos, 5 formações e 15 inscrições
  5. Cria uma consulta que mostre os formandos inscritos em cada formação com a data de inscrição
  6. Cria uma consulta de totais que conte o número de inscrições por formação
  7. Cria um formulário de inscrição com lista suspensa para selecionar o formando e a formação
  8. Cria um relatório agrupado por formação com a lista de formandos inscritos e total de inscrições
  9. Exporta o relatório para PDF
